## Draft GitHub Release Notes

### Len v0.4.1-alpha.1

This security-maintenance alpha updates Pillow from 12.2.0 to 12.3.0 and pypdf from 6.13.3 to 6.16.1. It does not change Len's application features, database schema, storage locations, accepted inputs, or local-first privacy model. No data migration is required.

Len is unfinished prerelease software and may contain defects or lose data. It has not been clinically validated and is not medical advice, diagnosis, treatment, monitoring, crisis support, or emergency software.

Len stores assessment responses, notes, databases, reports, and workbooks locally. It does not intentionally upload them and does not provide cloud synchronization, automatic backups, or encryption. Anyone who receives these files can read the sensitive information they contain.

Before updating, close Len and back up `phq9_tracker.sqlite` plus any reports you want to retain. Extract the new release into a new folder rather than overwriting the only working copy. Copy the backed-up database into the new folder, launch with `Launch Portable Len.bat`, and confirm the expected History records before deleting the old folder or backup.

The Windows executable is unsigned. Windows SmartScreen, organizational App Control, or another security product may warn about or block it. Do not weaken or disable security controls to run Len.

If you may be in immediate danger or need urgent help, contact local emergency services or an appropriate crisis resource. Len does not monitor responses or provide emergency help.
