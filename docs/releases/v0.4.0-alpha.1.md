## GitHub Release Notes

### Len v0.4.0-alpha.1

This is the first Len-branded public alpha for Windows 11 64-bit. It is unfinished prerelease software and may contain defects or lose data. It has not been clinically validated and is not medical advice, diagnosis, treatment, monitoring, crisis support, or emergency software.

Len supports local PHQ-9 and GAD-7 check-ins, optional notes and treatment events, History and Review views, a clinician-discussion PDF, and a normalized XLSX Analysis Workbook. PHQ-9 and GAD-7 can be recorded independently or together, and generated outputs can include either or both questionnaires.

Len is local-first: it does not intentionally upload assessment responses, notes, databases, reports, or workbooks. The application does not provide cloud synchronization, automatic backups, or encryption. Anyone who receives a database, PDF, or workbook can read the sensitive information it contains.

Before first use, allow Windows Security or another trusted antivirus product to scan the ZIP. Extract the entire ZIP into a normal user-writable folder and start Len with `Launch Portable Len.bat`. The app is unsigned, so Microsoft Defender or SmartScreen may warn that it is unfamiliar. Do not disable antivirus protection or override a warning you do not understand.

Before updating, close Len and back up `phq9_tracker.sqlite` plus any reports you want to retain. Extract a new release into a new folder instead of overwriting the only working copy. Copy the backed-up database into the new folder, launch with the portable batch file, and confirm the expected History records before deleting the old folder or backup.

If you may be in immediate danger or need urgent help, contact local emergency services or an appropriate crisis resource. Len does not monitor responses or provide emergency help.
