## Compatibility and Upgrade Guidance

- PHQ-9 and GAD-7 remain the only included questionnaires.
- Existing PHQ-9/GAD-7 compatibility tables remain in place while new immutable definition snapshots and normalized versioned submissions/responses are added transactionally and idempotently.
- Close Len and back up the complete `phq9_tracker.sqlite` file before upgrading. Reports are separate files and should be backed up independently when needed.
- Extract the new portable release into a new folder rather than overwriting the prior folder. Copy the closed database backup into the new folder before using `Launch Portable Len.bat`, then confirm the expected History records before removing the previous copy or backup.
- Direct `PHQ9Tracker.exe` launch uses `%LOCALAPPDATA%\PHQ9Tracker`; the portable launcher stores the database and reports beside the launcher. Changing launch methods can make intact data appear missing because the locations are separate.
- Startup migrations are designed to preserve and reconcile historical records without duplication. Transaction rollback is not a substitute for a user-controlled backup.

## Draft GitHub Release Notes

### Len v0.5.0-alpha.1

This alpha introduces a versioned, extensible questionnaire framework while keeping PHQ-9 and GAD-7 as the only included questionnaires. Today's Check-In now uses a compact roster and one definition-driven active form, with explicit unanswered responses, independent completion state, and preservation of unsaved answers when switching forms.

Review, trends, PDF reports, and the Analysis Workbook are definition-version-aware. Report selection begins with the date range, and incompatible questionnaire-definition versions are identified rather than blended. Len stores immutable definition snapshots and normalized versioned submissions/responses while preserving the compatibility tables. Migration and backfill are transactional, idempotent, and designed to preserve historical records without duplication.

Custom questionnaire authoring and import remain deferred. Raw-only or future custom instruments receive no automatic clinical interpretation, severity, risk, diagnosis, or treatment recommendations. PHQ-9 Item 9 behavior remains exclusive to PHQ-9.

Len is unfinished alpha software and may contain defects or lose data. Close Len and back up the complete `phq9_tracker.sqlite` file before updating. Extract the release into a new folder, copy the closed backup into that folder for portable use, launch with `Launch Portable Len.bat`, and verify History before removing the prior copy or backup.

Len has not been clinically validated and is not medical advice, diagnosis, treatment, monitoring, crisis support, or emergency software. The Windows executable remains unsigned; Windows SmartScreen, organizational App Control, or another security product may warn about or block it. Do not weaken or disable security controls to run Len.
