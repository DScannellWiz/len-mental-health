# Len Support Guide

Len offers best-effort support for software and repository questions. It does not provide medical interpretation, clinical advice, monitoring, crisis support, or emergency assistance.

## Before Requesting Support

1. Confirm that you obtained Len from the [official GitHub Releases page](https://github.com/DScannellWiz/len-mental-health/releases).
2. Read the [README](README.md), especially the storage-mode, backup, Windows-security, and medical-boundary sections.
3. Search the public [issue tracker](https://github.com/DScannellWiz/len-mental-health/issues) without entering any personal or health information.
4. Reproduce the problem with newly created fictional data whenever possible.

## Ordinary Software Problems

Use the repository's [bug-report form](https://github.com/DScannellWiz/len-mental-health/issues/new?template=bug_report.yml) for a reproducible software defect.

Include only:

- the Len version and official release source;
- the Windows version and launch mode;
- concise reproduction steps using fictional data;
- expected and actual software behavior; and
- exact non-health error or security-warning text.

The public project address, `projectmentalhealthtracker@gmail.com`, is a fallback for software and repository administration. It is not continuously monitored. Public issues are preferred for ordinary non-sensitive software reports so others can search and learn from the resolution.

## Security Vulnerabilities

Do not open a public issue for a suspected vulnerability. Follow the [Security Policy](SECURITY.md) and use [GitHub private vulnerability reporting](https://github.com/DScannellWiz/len-mental-health/security/advisories/new).

## Information That Must Not Be Submitted

Do not submit or email:

- a Len database;
- a generated PDF, workbook, export, or log containing entered data;
- assessment responses, scores, journal entries, treatment information, or clinician information;
- PHI, PII, credentials, private correspondence, or identifying file paths; or
- screenshots containing health information, names, account information, or other private data.

If a screenshot is essential to an ordinary software report, first confirm that it contains no entered health data, identity details, account information, or identifying file paths. Prefer exact error text over a screenshot.

## Medical, Crisis, and Emergency Boundary

Do not use Len, this repository, its issue tracker, private vulnerability reporting, or the project email for medical questions, interpretation of assessment results, crisis support, or emergency help.

If you may be in immediate danger or need urgent help, contact local emergency services or an appropriate crisis resource. Len does not monitor entries or support requests.
