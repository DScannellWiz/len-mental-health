## Patch Scope and Upgrade Guidance

This patch corrects the artificial definition v1/v2 analytical split in Review recent and long-term trends, item profiles and comparisons, treatment-cycle displays where applicable, PDF trends and profiles, and Analysis Workbook derived analytics. PHQ-9 v1/v2 form one explicitly approved chronological analytical series; GAD-7 v1/v2 form a separate approved series. A scoring/profile signature guard prevents combining definitions with different analytical meaning. Unknown or incompatible future versions remain separate.

Stored submissions, immutable definition snapshots, and raw/detail/check-in provenance retain their exact definition versions. Historical v1 daily responses display numeric `0`-`3` values; v2 displays `Not present / Mild / Moderate / High`. Daily severity totals, the separate derived 14-day frequency conversion, and PHQ-9 Item 9 exclusivity are unchanged. This release adds no questionnaire, scoring strategy, clinical interpretation, or data migration.

Close Len and back up the complete `phq9_tracker.sqlite` file before upgrading. Extract the new portable ZIP into a new folder. For portable use, copy the closed database backup into the new folder before starting `Launch Portable Len.bat`, then confirm expected History records before removing a prior copy or backup. Direct `PHQ9Tracker.exe` launch uses `%LOCALAPPDATA%\PHQ9Tracker`; the portable launcher uses storage beside itself.
